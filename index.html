开始之前

这是一个 网页解谜 / ARG 类型的作品。你不扮演任何角色——你只扮演你自己。

你要看的不是一篇小说，而是一堆残破的网页：一个被清空的中学贴吧、几张旧报纸、 一个还挂在校园内网里的门卫登记系统。它们不会主动告诉你发生了什么， 你得自己去翻、去比对、去把碎片拼起来。

这个游戏怎么玩
  • 没有「下一关」按钮，没有提示按钮，没有进度条。页面本身就是线索。
  • 贴吧页面右上角有站内搜索。这是你最重要的工具，会用很多次。
  • 有几页不会出现在任何链接里，只能靠搜索找到。搜什么关键词，要你自己想。
  • 同一件事往往在好几个地方都能查到（报纸、日志、聊天记录、帖子）。 卡住的时候，换个地方翻，不要死磕一个页面。
  • 部分页面需要输入核对口令才能打开。口令一定来自你已经读到过的内容， 不需要任何外部知识、不需要密码学基础。
  • 进度自动存在你自己的浏览器里，关掉页面不会丢。
游玩要求
  • 推荐用电脑浏览器（Chrome / Edge）。手机端能完整游玩，但排版是另一种样子。
  • 无需注册、无需登录、无需下载。
  • 本作品不收集任何数据：没有埋点、没有账号、没有服务器。 唯一写入你设备的是游玩进度，清一下浏览器缓存就会重置。
  • 建议不要看攻略。这个故事的价值全在"自己拼出来"的那一刻， 被剧透之后体验会掉一大半。
关于本作品
  • 全站是纯静态网页，没有一次外部请求——界面、头像、旧报纸版面、收音机频率图由 HTML 与 CSS 写成； 收音机里那段信号是浏览器实时合成的。
  • 站内出现的照片（相册、帖子配图）为 AI 生成图像，仅用于本作品的虚构叙事， 不含任何真实人物、地点或第三方素材。
  • 页面里出现的「贴吧」「吧务」「快照」「空间」等是通用形式， 不代表任何具体平台，也不存在任何真实的第三方链接。
  • 作品中不存在需要你离开游戏、前往真实社交平台、或提供任何个人信息才能完成的环节。 如果某个页面要求你登录、付款或填写真实信息，那它一定是假的，请立刻关掉。
  • 本作品为个人非商业创作。
