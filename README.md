# 《滏阳没有海》

一个纯静态的网页解谜 / ARG 作品。

> 往南走，一直走到能看见海的地方，就没人认得她了。

玩家在一个被清空的县中学贴吧残骸里翻找——残缺的楼层、值班日志、旧报纸、聊天记录，
拼出 2003 年和 2014 年发生在同一所学校的两件事。

## 开始玩

**线上**：https://zzy6-a.github.io/fuyang/

**本地**：直接双击 `index.html`（`file://` 也能跑），或者

```bash
python3 -m http.server 8765
# 打开 http://localhost:8765/
```

## 结构

```
index.html      公告 / 游戏提示（入口）
  └ start.html  拾遗论坛 · 一个 2026 年的求助帖
      └ archive.html  网页时光机（自己搜「十二中吧」）
          └ bar.html  十二中吧 · 网页存档（正文从这里开始）
```

## 说明

- **纯静态**：没有构建步骤、没有后端、没有依赖、没有一次外部请求。
- **界面、头像、旧报纸版面、收音机频率图**由 HTML 与 CSS 写成；收音机里那段信号是浏览器实时合成的摩斯码。
- **站内照片为 AI 生成图像**，仅用于本作品的虚构叙事，不含任何真实人物、地点或第三方素材。
- 页面里出现的「贴吧」「吧务」「快照」「空间」等是通用形式，不代表任何具体平台。
